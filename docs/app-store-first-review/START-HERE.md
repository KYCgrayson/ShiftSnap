# IShift 首次送审资料

这套资料用于填写草稿，不代表 Apple 后台已填写或 App 已送审。

1. 阅读 submission-checklist.md：前半部是候选版本的具体问题，后半部是 Safari 各页面对应栏位。
2. 在 App Store Connect 对应语言复制 metadata.md 的「Draft」及说明正文。不要复制 Markdown 标记、字数或内部核查备注。
3. 截图使用压缩包 screenshots 中的原生尺寸 JPG（由真实模拟器 PNG 转存，无缩放），按装置尺寸分别上传。画面语言以档案说明为准。
4. reviewer-attachment 是审核员可选的合成辨识样本，不要上传到商店截图栏。
5. support-page-draft.md 与 privacy-page-draft.md 为网站草稿。兩頁已部署至 appai.info，使用 appai@appai.info；網址及 Apple 已儲存欄位以 current-status.md 為準。
6. 审核帐号密码和负责人电话直接填 Apple 后台；不要放入截图、Git 或公开网页。
7. 修正已知审核问题并验证候选版以后，再选对应构建、储存，由负责人按最终送审。

最新送審狀態與責任分工請先看 current-status.md。
