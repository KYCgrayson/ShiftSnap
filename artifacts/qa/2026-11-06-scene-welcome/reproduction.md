# iOS 27 native reproduction

Use disposable iOS 27 simulator(s) with synthetic data. The normal entry uses the real Expo Router, signed-out start and guest session. The separate authenticated app uses a QA-only initializer for a localhost Supabase fixture. Both builds use the same native app code and com.shiftsnap.app bundle ID. Keep a copy of each build before building the next entry. Never use a production project, account, or device for these tests.

1. Start the fixture from an isolated temporary working directory with Node and the absolute path to fixture-digest.mjs in this directory. It binds to 127.0.0.1:55439. Keep raw logs temporary; save only request method, path, synthetic group ID, image status, byte counts and digests.
2. From apps/mobile/ios build an SDK 27 Release simulator target. Use ENTRY_FILE=<repo>/node_modules/expo-router/entry.js, EXPO_NO_DOTENV=1, EXPO_PUBLIC_SUPABASE_URL=http://127.0.0.1:55439, EXPO_PUBLIC_SUPABASE_ANON_KEY=local-qa-only as environmental variables. Invoke xcodebuild -workspace ShiftSnap.xcworkspace -scheme ShiftSnap -configuration Release -sdk iphonesimulator -destination id=<UDID> -derivedDataPath <derived> ONLY_ACTIVE_ARCH=YES IPHONEOS_DEPLOYMENT_TARGET=15.0 CODE_SIGNING_ALLOWED=YES CODE_SIGN_IDENTITY=- build. Install the resulting Build/Products/Release-iphonesimulator/IShift.app with xcrun simctl install onto a clean simulator.
3. Copy Host.swift, VisibilityTests.swift, and project.rb into a fresh directory. Run ruby project.rb with the xcodeproj gem installed. Run xcodebuild test -project Visibility.xcodeproj -scheme Visibility -destination id=<UDID> -collect-test-diagnostics never -parallel-testing-enabled NO -only-testing:VisibilityUI/VisibilityTests/testFreshWelcomeAndLifecycle -resultBundlePath <fresh>.xcresult. The program exercises signed-out routes, interrupted/returning sessions, native URL delivery and guest persistence.
4. Build a second copy with ENTRY_FILE=<repo>/apps/mobile/tests/native-reliability.entry.js, EXPO_PUBLIC_QA_LOCALE=zh-TW, and a fresh EXPO_PUBLIC_QA_RUN_ID. Install on a separate clean simulator. This entry obtains a synthetic session from the local fixture, then opens the ordinary app screens. Run the same test command with testRealRosterGroupWarning and a new result bundle.
5. Export attachments using xcrun xcresulttool export attachments --path <result>.xcresult --output-path <directory>. The JSON manifest maps human-readable names to exported files.

For the preference regression, run testEnglishPreferenceOnChineseDeviceAfterRelaunch after the normal-entry guest test on the same installed app. It switches from 繁體中文 to English in Settings and cold-launches again with the zh-Hant-TW device-language override.

Validate the redacted final fixture capture with node verify-boundary.mjs <repo>/apps/mobile/assets/ishift-demo-roster-september-2026.png final-native-requests.json. The verifier checks OCR, uploaded and read-back bytes/digest against the original sample, pinned group ID and final persisted image status.
