# IShift 支援中心｜待加入已驗證的客服管道後發布

**如何從照片建立班表？** 在「掃描」選擇班表照片，核對辨識出的日期、人員、班別代號及時間，再儲存。照片辨識需要網路連線；請只上傳你有權處理的資料。

**手機日曆為什麼只顯示 B？** B 是原始班表的代號。到「設定 → 班表日曆」，打開「加入班別名稱」或「加入姓名」，檢查預覽，再確認匯出。只變更設定不會立即更改已匯出的事件。

**如何分享班表？** 在 App 的「日曆」切換至所需月份，點選分享班表，預覽圖片後再選擇傳送對象。分享前請確認圖片沒有不想公開的個人資料。

**如何回報問題？** 請提供 App 版本、iOS 版本以及發生問題的操作步驟。請勿寄送密碼、登入驗證碼或未遮蔽的真實員工班表。

發布前：加入經負責人確認且有人收件的聯絡方式與公開隱私政策連結，測試外部訪客可開啟、寄信可收件。帳號刪除說明須等實際功能完成並驗證後才加入。本檔不是已上線的 Support URL。
