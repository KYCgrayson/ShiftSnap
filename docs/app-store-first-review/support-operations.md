# 客服收件及发布门槛
应用将问题送入 Supabase 私有 support_requests 表。用户只能通过已认证 RPC 递交，不可查询其他人的消息。每次成功会返回案件 UUID。客户端不能读取此表；项目营运人员使用受权限控制的 Dashboard 查看。根据 user_id 在 Auth 后台查用户联系方式，勿公开案件或凭证。
发布负责人须安排值班人定期读信并实际回复。正式发布前，用专用测试帐号验证：送出 → 后台看到同一案件编号 → 营运人员可联系测试收件者。离线或 RPC 尚未部署时表单必须保留文字并显示未确认，不应声称收到。
App Store Support URL 与 Privacy Policy URL 仍须以实际公开域名、对未登入及已注销用户也可用的客服联络方式上线，不能用后台表名、私有 GitHub 文件或未经许可的私人信箱代替。
