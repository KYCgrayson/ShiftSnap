# IShift 隱私權政策｜負責人核對稿，尚不可直接發布

IShift 協助使用者將班表照片轉成可核對的班次，查看班表，並依自己的選擇匯出到手機行事曆或分享班表圖片。

**帳號及班表資料。** 建立帳號時，IShift 使用電子郵件、顯示名稱及帳號識別碼提供登入與帳號功能。上傳班表時，影像及辨識結果可能包含班表上列出的人員姓名、日期、班別代號、時間及休假資訊。請只使用有權上傳及分享的資料。

**服務提供者。** IShift 使用 Supabase 處理登入與儲存資料。使用影像辨識時，所選班表照片會傳至 Google Gemini，以擷取班次。請在送出前核對照片範圍。此段文字不能取代 App 內、上傳前的明確同意。

**誰能看到資料。** 個人與群組功能依帳號、群組及分享設定提供存取；主動匯出班表圖片後，收到圖片的人可以自行保存或轉傳。匯出到手機行事曆時，事件會寫入選取的班表日曆，能存取該日曆的人可能看到事件。分享前可檢查內容，並選擇是否顯示姓名等資訊。

**設備及權限。** 相機或相簿用於選取班表；手機行事曆權限用於匯出及更新班次；儲存分享圖片使用相簿新增權限。手機也會保留部分已載入班表供離線查看。關閉權限不會自動撤回已傳給他人的圖片。

**發布前必填並驗證，不能留空或照抄保證：**
- 真實營運者、適用／生效日期、有效且有人回覆的聯絡方式。
- 班表、帳號、備份、診斷及服務提供者資料各自的保留期限或決定準則；核實 Google 專案條件與實際日誌，不承諾尚未證實的零留存。
- 收集哪些使用紀錄、裝置及錯誤資訊、收集目的與服務對象；與 App 內政策、Apple 隱私標籤同步。
- 帳號刪除入口、實際完成流程、資料保留例外，以及已匯出／他人持有副本如何處理。待功能驗收後再刊登操作步驟。
- 發布後以未登入瀏覽器測試永久 HTTPS 網址，在 App Store Connect 與 App 內開啟同一政策。
